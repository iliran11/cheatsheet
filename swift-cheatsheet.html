Unwrapping Optionals 🎁

if let unwrap in a scope

Runs the block only if not nil. Unwrapped value lives inside the braces.

if let photo = optionalPhoto {
    show(photo)              // non-optional here
}
if let photo {  // shorthand, same name
    show(photo)
}

guard let early exit

Exits if nil (return / throw). Value stays available after the guard.

guard let photo = optionalPhoto else {
    return
}
show(photo)  // usable for rest of function

?? and ? quick tools

?? default if nil · ?. optional chaining · ! force (crashes if nil)

name = optionalName ?? "Anonymous"
count = optionalPhoto?.tags.count   // Optional Int
photo = optionalPhoto!              // ⚠️ avoid

Structs 🧱

init creating an instance

Free memberwise initializer — one parameter per stored property:

let p = ModelPhotoPlacement(photo: myPhoto, slot: mySlot)

init(_) no label

Use _ in a custom init to drop the label:

struct StructExample {
    let assets: [Asset]
    init(_ assets: [Asset]) { self.assets = assets }
}
let ex = StructExample(myAssets)  // no label 🎉

let stored constant

Must be initialized — at declaration or via init. Can't change after.

let photo: ModelPhoto    // set once via init
let internalID = UUID()  // default value

var { } computed property

No stored value — recalculated on every access.

var displayName: String {
    "\(photo.name) @ \(slot.id)"
}

get set setter

Computed property with a setter — newValue is the incoming value.

var title: String {
    get { photo.name }
    set { photo.name = newValue }
}
p.title = "Sunset"  // calls set

private keep it inside

Visible only inside the struct.

private func validate() -> Bool { !photo.name.isEmpty }

SwiftUI 🎨 views

View the basic view

A struct conforming to View — body is a computed property. Params = stored properties.

struct HelloView: View {
    let name: String          // param
    var body: some View {
        Text("Hello, \(name)!")
    }
}
HelloView(name: "Maya")      // usage

ForEach loop in a view

Creates a view per element. Items need a stable id.

ForEach(placements) { p in   // if Identifiable
    PhotoView(placement: p)
}
ForEach(names, id: \.self) { Text($0) }
