Swift Language 🍎

Data Structures 🗂️

Dictionary key-value pairs

Unordered key-value pairs. Subscript returns an optional. Lookup is O(1) average.

var ages: [String: Int] = ["Ann": 30, "Bo": 25]
let age = ages["Ann"]
ages["Cy"] = 40
for (name, age) in ages {
    print(name, age)
}

Set unique elements

Unordered collection of unique, Hashable elements. contains is O(1) average.

var tags: Set<String> = ["sunset", "beach"]
tags.insert("ocean")
tags.contains("beach")
tags.intersection(["beach", "lake"])

Optional Binding 🎁

if let unwrap in a scope

Runs the block only if not nil. Unwrapped value lives inside the braces.

if let photo = optionalPhoto {
    show(photo)
}
if let photo {
    show(photo)
}

guard let early exit

Exits if nil (return / throw). Value stays available after the guard.

guard let photo = optionalPhoto else {
    return
}
show(photo)

?? and ? quick tools

?? default if nil · ?. optional chaining · ! force (crashes if nil)

name = optionalName ?? "Anonymous"
count = optionalPhoto?.tags.count
photo = optionalPhoto!

Structures 🧱

init creating an instance

Free memberwise initializer — one parameter per stored property:

let p = ModelPhotoPlacement(photo: myPhoto, slot: mySlot)

init(_) no label

Use _ in a custom init to drop the label:

struct StructExample {
    let assets: [Asset]
    init(_ assets: [Asset]) { self.assets = assets }
}
let ex = StructExample(myAssets)

let stored constant

Must be initialized — at declaration or via init. Can't change after.

let photo: ModelPhoto
let internalID = UUID()

var { } computed property

No stored value — recalculated on every access.

var displayName: String {
    "\(photo.name) @ \(slot.id)"
}

get set setter

Computed property with a setter — newValue is the incoming value.

var title: String {
    get { photo.name }
    set { photo.name = newValue }
}
p.title = "Sunset"

private keep it inside

Visible only inside the struct.

private func validate() -> Bool { !photo.name.isEmpty }

Arrays 📦

[ ] array literal

Ordered, zero-indexed collection — type is inferred from its elements.

let names = ["Ann", "Bo", "Cy"]
var scores: [Int] = []

repeating:count: preallocate

Builds an array of n copies of a value — handy for fixed-size buffers or grids.

var grid = Array(repeating: 0, count: 4)

→ [0, 0, 0, 0]

repeating:count: with strings

The repeated value can be any type — here, a placeholder string.

var tags = Array(repeating: "empty", count: 3)

→ ["empty", "empty", "empty"]

nested repeating 2D grid

The inner array (3 falses) is one row — [Bool] is shorthand for Array<Bool>, so this init is the same as Array(repeating: false, count: 3). repeating that row 3 times builds a 3×3 grid.

let row = [Bool](repeating: false, count: 3)
var board = Array(repeating: row, count: 3)

→ [[false, false, false],
  [false, false, false],
  [false, false, false]]

AsyncStream 🌊

AsyncStream build a stream

Wraps a callback-based API as an async sequence. Call yield for each value, finish when done.

let stream = AsyncStream<Int> { continuation in
    continuation.yield(1)
    continuation.yield(2)
    continuation.finish()
}

for await consume a stream

Iterates values as they arrive, suspending between each one.

for await value in stream {
    print(value)
}

onTermination cleanup

Runs when the consumer stops iterating or the stream finishes — cancel underlying work here.

continuation.onTermination = { _ in
    stopListening()
}

bufferingPolicy back-pressure

Caps how many unconsumed values are buffered when the consumer runs slower than the producer.

let stream = AsyncStream<Int>(bufferingPolicy: .bufferingNewest(1)) { continuation in
    continuation.yield(1)
}

Identifiable, Hashable, Equatable 🪪

Identifiable stable identity

Requires an id property. Lets SwiftUI track items across a collection, e.g. in ForEach.

struct Photo: Identifiable {
    let id = UUID()
    let name: String
}

Equatable == comparison

Requires ==. Synthesized automatically if all stored properties are Equatable.

struct Photo: Equatable {
    let id: UUID
    let name: String
}
photoA == photoB

Hashable use in Set / Dictionary key

Extends Equatable with a hash(into:). Also synthesized automatically for simple types.

struct Photo: Hashable {
    let id: UUID
}
let seen: Set<Photo> = [photoA, photoB]

SwiftUI 🎨

Views 🖼️

View the basic view

A struct conforming to View — body is a computed property. Params = stored properties.

struct HelloView: View {
    let name: String
    var body: some View {
        Text("Hello, \(name)!")
    }
}
HelloView(name: "Maya")

ForEach 🔁

ForEach with Identifiable

Conform to Identifiable and ForEach can find the id on its own — the safe way to iterate.

struct Placement: Identifiable {
    let id: UUID
    let photo: ModelPhoto
}
ForEach(placements) { p in
    PhotoView(placement: p)
}

ForEach without Identifiable

No Identifiable conformance — fall back to id: \.self. Only safe when elements are unique.

let names: [String] = ["Maya", "Ori", "Tal"]

ForEach(names, id: \.self) { Text($0) }

ScrollView 📜

ScrollView vertical by default

Wraps content that's taller than the screen in a scrollable container.

ScrollView {
    VStack {
        ForEach(items) { item in
            RowView(item: item)
        }
    }
}

.horizontal axis

Pass an Axis.Set to scroll sideways. Hide the bar with showsIndicators.

ScrollView(.horizontal, showsIndicators: false) {
    HStack {
        ForEach(photos) { PhotoThumb(photo: $0) }
    }
}

LazyGrid 🧩

LazyVGrid vertical grid

Lays out columns via GridItem, grows downward. Rows are built lazily as they appear.

let columns = [
    GridItem(.flexible()),
    GridItem(.flexible())
]
ScrollView {
    LazyVGrid(columns: columns) {
        ForEach(photos) { PhotoThumb(photo: $0) }
    }
}

LazyHGrid horizontal grid

Same idea, rotated — uses rows and grows sideways.

let rows = [GridItem(.flexible()), GridItem(.flexible())]
ScrollView(.horizontal) {
    LazyHGrid(rows: rows) {
        ForEach(photos) { PhotoThumb(photo: $0) }
    }
}

Image 🌄

Image from an asset

Loads a bitmap or vector image from the asset catalog by name.

Image("avatar")

.resizable() allow resizing

Without it, an image renders at its native size and ignores frame modifiers.

Image("avatar")
    .resizable()

.frame() set the size

Sets the width/height the image is laid out into — a resizable image scales to fit it.

Image("avatar")
    .resizable()
    .frame(width: 80, height: 80)

.scaledToFill() fill the frame

Scales proportionally to fill the frame — may overflow its bounds.

Image("avatar")
    .resizable()
    .scaledToFill()
    .frame(width: 80, height: 80)

.clipped() crop the overflow

Cuts off content that extends past the frame's bounds.

Image("avatar")
    .resizable()
    .scaledToFill()
    .frame(width: 80, height: 80)
    .clipped()
